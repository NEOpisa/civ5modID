# Era das Ideologias — Civilization V

Mod para **Civilization V: Brave New World**, instalado como DLC para funcionar no **Multijogador normal**, sem o menu MODS.

## Baixar

- **Windows:** [EraDasIdeologias-Windows.zip](https://github.com/NEOpisa/civ5modID/releases/latest/download/EraDasIdeologias-Windows.zip)
- **Linux** (versão nativa ou Proton): [EraDasIdeologias-Linux.zip](https://github.com/NEOpisa/civ5modID/releases/latest/download/EraDasIdeologias-Linux.zip)

## Instalar

Feche o jogo e extraia o zip.

- **Windows:** dois cliques em `instalar-windows.bat`.
- **Linux:** abra um terminal na pasta extraída e rode `sh instalar-linux.sh`.

Para remover: `instalar-windows.bat remover` ou `sh instalar-linux.sh --remover`.

Todos os jogadores precisam da mesma versão. Se a Steam verificar os arquivos do jogo, instale de novo.

## Jogar

Um Jogador ou Multijogador normal. Em Configuração Avançada, a DLC **Era das Ideologias** vem marcada.

A versão nativa do Linux só joga online com Linux/Mac nativos; pelo Proton, joga com quem está no Windows.

As regras completas estão em [LEIA-ME.md](EraDasIdeologias/LEIA-ME.md).
